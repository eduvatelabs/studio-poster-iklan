# Studio Poster Iklan

Aktiviti interaktif **Reka Bentuk dalam Perniagaan** (RBT, Bab 3 — Reka Bentuk sebagai Instrumen Pemasaran) oleh **Eduvate Labs**.

Murid membina poster pengiklanan langkah demi langkah:

1. Pilih latar belakang
2. Letak gambar produk (atau muat naik gambar sendiri)
3. Tulis tajuk & ayat
4. Tambah hiasan / sticker
5. Tambah ikon & maklumat hubungan
6. Labelkan 6 ciri pengiklanan berkesan dengan ayat mudah

Akhir sekali, poster dan label dijana sebagai satu gambar JPG untuk dimuat turun dan dihantar kepada guru.

Satu fail `index.html` sahaja — tiada pemasangan diperlukan. Boleh dihoskan terus dengan GitHub Pages.
